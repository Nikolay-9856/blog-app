# «Заметки» — блог-платформа (кейс-задача № 3)

Веб-приложение на Python/Flask + SQLite.

## Возможности
- регистрация и вход (пароли хранятся в виде хеша PBKDF2/scrypt — `werkzeug.security`);
- написание, редактирование и удаление собственных постов;
- теги к постам, фильтр ленты по тегу, сортировка (новые / старые / по заголовку);
- подписка на авторов и лента, собранная только из постов подписок;
- просмотр публичных постов без регистрации;
- скрытые посты «только по запросу»: читатель отправляет запрос, автор одобряет или отклоняет его;
- комментарии (удалить может автор комментария или автор поста).

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python seed.py        # необязательно: демо-пользователи anna / dmitry / olga, пароль secret1
python app.py         # http://127.0.0.1:5000
```
Пустую базу можно создать командой `flask --app app init-db`.

## Тесты
```bash
pytest -q
```

## Структура
```
app.py          маршруты и бизнес-логика
schema.sql      схема БД (7 таблиц)
seed.py         демо-данные
templates/      шаблоны Jinja2
static/         стили
tests/          автотесты pytest
```
Для работы в сети задайте переменную окружения `BLOG_SECRET` (секретный ключ сессий).
